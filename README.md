# Deskcrumbs for Homebrew

[Deskcrumbs](https://deskcrumbs.com) is a free Mac app: Markdown sticky notes that live on your desktops, saved as plain files.

```sh
brew install --cask laureldaigneault-hehim/tap/deskcrumbs
```

Deskcrumbs updates itself (Sparkle), so `brew upgrade` leaves it alone. This cask is updated automatically with every release.
